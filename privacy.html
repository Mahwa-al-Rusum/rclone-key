Privacy policy

Last updated: 18 November 2026.

This Google Cloud app ("rclone") is used only by its owner to reach their own Google Drive through the open-source program rclone, which runs on the owner's own computer.

  • The app reads and writes files only in the owner's own Google Drive, on the owner's command.
  • The sign-in token is stored only on the owner's computer, in rclone's configuration file.
  • No data is sent to, collected by, or stored on any server run by the app's owner, and nothing is shared with, sold to, or used by anyone else.
  • The use of data received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
  • Access can be withdrawn at any time at myaccount.google.com/permissions.
